Snake for Linux

Play without installing:
    Double-click snake-multiplayer, or run ./snake-multiplayer in a terminal.

Install with an entry in the application menu:
    Open a terminal in this folder and run ./install.sh
    Nothing needs root. The game goes to ~/.local/bin.

Remove it again:
    ./uninstall.sh

More: https://github.com/Daniel-the-Boehm/Snake-Multiplayer-Linux
